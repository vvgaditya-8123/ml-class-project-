# 🚀 Real-Time Emoji Detection & Keystroke Prediction

An intelligent machine learning system that predicts matching emojis in real-time as you type, complete with an interactive desktop GUI, sub-2ms latency, top-5 confidence distributions, and full model evaluation.

---

## 📌 Features

- **⚡ Sub-2ms Real-Time Inference**: Predicts emojis dynamically on every keystroke (`<KeyRelease>` with debouncing) without stutter or lag.
- **🎯 20 Emoji Classes**: Mapped directly from Twitter / social media emoji benchmark dataset (`Train.csv`, `Mapping.csv`, `Test.csv`).
- **🔍 Multi-Scale Feature Union**:
  - Word N-grams (1, 2) with sublinear TF scaling.
  - Character boundary N-grams (3, 5) (`char_wb`) to capture root tokens, word stems, hashtags, and typing prefixes before words are finished.
- **🎨 Interactive Modern GUI**:
  - Live Hero emoji card showing the top prediction and probability.
  - Top 5 suggestion bar (like iOS/Android keyboard) with clickable pills to insert emojis directly into the text.
  - Confidence progress meters for probability distribution.
  - Quick test preset buttons (Christmas, Fire, Hilarious, Sunny, Love, USA, Photography, 100%).
  - Text statistics (char/word counter) and live latency timer.
- **🧪 Production Ready**: Includes clean modular preprocessing, standalone inference engine (`predict.py`), training pipeline with validation evaluation (`train.py`), and automated unit tests (`test_pipeline.py`).

## 🏃 Running the Application

### 1. Launch the Real-Time Typing GUI
Run the GUI to see predictions update live as you type:
```bash
python gui.py
```
*(Or using the venv python: `.\.venv\Scripts\python.exe gui.py`)*

### 2. Run Single Predictions from CLI
```bash
python predict.py "Merry Christmas and a happy new year!"
python predict.py "This beat is straight fire"
python predict.py "LMAO that is hilarious"
```

### 3. Re-train the Model & Evaluate
To re-run the training pipeline, calculate validation scores, and update `test_predictions.csv`:
```bash
python train.py
```

### 4. Run Automated Tests
```bash
python test_pipeline.py
```

## 📊 Model Architecture & Performance

- **Preprocessing**: HTML entity unescaping, `@user` mention cleaning, URL stripping, hashtag expansion (`#happy` -> `happy #happy`).
- **Feature Extraction**: TF-IDF FeatureUnion (Word n-grams 1-2: 45k features, Char n-grams 3-5: 35k features).
- **Classifier**: Multi-class L-BFGS Logistic Regression (C=1.2).
- **Validation Metrics (20 classes)**:
  - **Top-1 Accuracy**: ~37% (vs 5% random baseline)
  - **Top-3 Accuracy**: ~60%
  - **Top-5 Accuracy**: ~71%
- **Single Keystroke Latency**: ~1.5 milliseconds
